# 功能开发计划与现有能力梳理

> 面向产品能力的路线图。当前能力按 2026-09-04 的实现标注，避免将计划误写为已交付功能。

## 1. 当前用户可见能力

| 场景 | 状态 | 用户可做什么 | 实现入口 |
|---|---|---|---|
| 文本迭代 | 已实现 | 输入任务、领域、轮数和阈值；实时查看 token、每轮审查、评分趋势和最终文本 | 工作台 `/`、`GET /api/stream` |
| 文件工作区迭代 | 已实现 | 选择目录后让 Agent 读写文件、执行验证工具，查看工具事件与最终快照 | 工作台 `/`、`GET /api/stream_files` |
| 停止工作台运行 | 已实现 | 对已取得 `run_id` 的运行发送停止请求 | `POST /api/stop` |
| 长任务管理 | 已实现 | 创建代码任务、启动/暂停/恢复/取消，查看子任务进度和实时日志 | `/tasks`、`/tasks/:id`、`/api/tasks/*` |
| 每轮记录 | 部分实现 | 长任务执行时可读取已保存的草稿和 Critic 结果 | 检查点 API；当前主要用于展示，不构成完整恢复机制 |
| 代码自愈 | 已实现，未接入 Web | Python 调用“生成/修复 → pytest → 日志回注 → 复跑” | `SelfHealingOrchestrator`、示例、benchmark |
| 基准评估 | 已实现基础框架 | 对 4 个 Python 小任务比较单次生成与自愈循环并生成 Markdown | `benchmark/run_benchmark.py` |

## 2. 产品边界

- 这是本地/受控环境的工作台，不是多租户服务：无登录、权限、审计后台或远程执行隔离。
- 文件模式能修改实际目录，也能执行 shell 命令。目录选择并不等于用户逐项确认变更。
- 当前“验证”在文件 Agent 工具和独立自愈循环中可用，但不是工作台的独立完成判定；工作台仍按 Critic 收敛逻辑结束。
- 文本、文件和长任务虽共享 Agent 能力，但入口、持久化和展示层仍是两条产品路径。
- 不提供 Demo/Mock 模式；首次体验需要有效模型配置。

## 3. 功能路线图

### F1：统一任务创建与模式选择（部分完成）

工作台已有文本/文件模式切换、工作区选择和过程展示；长任务页面仍单独创建任务，且仅提供手输路径。

下一步：把模式、工作区、阈值、最大轮数和验证策略组织为同一任务创建模型；从工作台可选择“一次迭代”或“可持久化长任务”。

验收：用户只需在一个入口完成配置，并清楚看见该任务会写入哪里、如何结束、是否持久化。

### F2：验证驱动的代码闭环（未完成）

将 `SelfHealingOrchestrator` 或等价统一验证层接入文件模式与长任务：显示验证命令、退出码、证据摘要和重试原因，并以验证结果参与完成判定。

验收：用户可以完整看到“失败证据 → 修复 → 复跑 → 通过/达到上限”，而不是只看到 Critic 分数。

### F3：文件变更预览与人工确认（未开始）

在写入、编辑或删除前汇总 diff、目标路径和风险；用户确认后才执行。保存操作日志，并提供安全、明确的回滚边界。

验收：任何写入前都有可读的变更预览；删除、覆盖和命令执行需要显式确认。

### F4：文档质量检查模式（未开始）

为 Markdown 提供确定性规则验证（结构、字数、链接、禁止占位符），并将发现项回注生成流程。

验收：用户能区分“模型审查意见”和“规则验证失败”，且失败证据可复现。

### F5：方案生成与计划校验模式（未开始）

提供结构化任务计划生成，校验 schema、子任务 ID、依赖存在性和环路，并在界面展示依赖图或等价视图。

验收：错误依赖和不完整计划会被规则层阻止或明确标记。

### F6：运行历史与复用（部分实现）

任务和检查点已写入 `.task_store/`，但没有运行参数快照、筛选/对比页面或真正的从检查点恢复。

下一步：保存模型、提示词版本、阈值、预算、验证器、证据摘要和停止原因；提供历史列表、对比和“从此处重新运行”。

### F7：评估中心与基准报告（部分实现）

已有 4 个代码任务和 Markdown 报告生成；没有页面、归档结果或稳定的跨运行比较。

下一步：版本化任务集和原始报告，明确模型/提示词/预算，并在前端呈现对比结果。任何宣传指标以归档结果为唯一来源。

## 4. 推荐发布顺序

1. F2：先把最有差异化的“验证驱动修复”闭环接入用户路径。
2. F3：随后补齐文件变更确认与边界校验，控制真实写入风险。
3. F1：统一一次性和长任务的创建体验。
4. F6：让运行结果可追溯、可复用。
5. F4、F5：扩展非代码任务。
6. F7：在已有可信运行数据后再做评估展示。
