# RefineLoop v0.1.0

RefineLoop 的首个公开版本把 Generator-Critic 实验发展为一条可运行的代码 Agent 工程闭环：Agent 在隔离 Git worktree 中修改代码，确定性验证提供失败证据并驱动修复，用户最终审阅 diff 后决定应用或丢弃。

## 亮点

- 验证驱动修复：pytest、lint、Python 脚本和 Node build 的真实退出结果参与完成判定。
- 安全变更：隔离 worktree、真实路径边界、受控命令 profile 和人工审批。
- 持久化与恢复：任务、检查点、工具历史、Trace 和 artifact 可在服务重启后继续使用。
- 可观测性：结构化链路日志、Token/耗时/失败指标和健康探针。
- 完整界面：新建任务、任务中心、修复闭环、Trace 回放和变更集审批。
- 开源交付：Docker Compose、固定故障 Demo、离线测试、CI、MIT License 和贡献文档。

## 快速体验

```bash
git clone https://github.com/wlunan/refine-loop.git
cd refine-loop
cp .env.example .env
python scripts/prepare_demo.py
docker compose up --build
```

打开 <http://127.0.0.1:8000>，选择准备脚本输出的 Demo 仓库，运行 README 中的固定修复任务。

## 已知限制

- 仅面向本地、单用户、受信环境，不提供认证或租户隔离。
- Benchmark 尚未形成足够有区分度的正式效果数据，本版本不声明自愈提升指标。
- Agent 修改和测试结果仍需人工审阅。
