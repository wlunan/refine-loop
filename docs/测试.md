## 推荐：文件模式（最能测出项目价值）

页面走的是 `/api/stream_files`，可同时测到：文件迭代、Critic 审查快照、`python_pytest` 可验证工具、自愈闭环。

**1. 先建一个极小工作区**，比如 `e:\ai-works\gc-test-workspace`，里面只放一个 ground truth 测试文件 `test_lru_cache.py`：

```python
from lru_cache import LRUCache


def test_basic_operations():
    cache = LRUCache(2)
    cache.put(1, 1)
    cache.put(2, 2)
    assert cache.get(1) == 1
    cache.put(3, 3)  # 淘汰最久未使用的 key 2
    assert cache.get(2) == -1
    cache.put(4, 4)  # 淘汰 key 1
    assert cache.get(1) == -1
    assert cache.get(3) == 3
    assert cache.get(4) == 4


def test_update_existing():
    cache = LRUCache(2)
    cache.put(1, 1)
    cache.put(1, 10)
    assert cache.get(1) == 10


def test_capacity_one():
    cache = LRUCache(1)
    cache.put(1, 1)
    cache.put(2, 2)
    assert cache.get(1) == -1
    assert cache.get(2) == 2
```

（这就是 `benchmark/tasks.py` 里的 lru_cache 任务，规模刚好：一个类两个方法，但能暴露边界 bug，Critic 有明确抓手。）
